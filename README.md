# 🚀 LoginNexus - Nexus Acadêmico

O **LoginNexus** é o portal de autenticação oficial do ecossistema **Nexus Acadêmico**. Desenvolvido com tecnologias modernas, ele oferece uma interface segura, rápida e intuitiva para que estudantes e docentes acessem seus recursos educacionais.

## 🌟 Principais Funcionalidades

- **Autenticação Segura**: Sistema de login robusto para proteção de dados acadêmicos.
- **Interface Moderna**: Design focado na experiência do usuário (UX), adaptável a diferentes dispositivos.
- **Ecossistema Integrado**: Ponto de entrada único para todas as ferramentas da plataforma Nexus.
- **Performance Otimizada**: Construído com Blazor para carregamento instantâneo e interações fluidas.

## 🛠️ Tecnologias Utilizadas

- **Frontend**: [Blazor WebAssembly](https://dotnet.microsoft.com/en-us/apps/aspnet/web-apps/blazor)
- **Framework**: .NET 8.0
- **Estilização**: CSS3 com foco em design responsivo
- **Ícones & Design**: Baseado em padrões modernos de UI/UX

## 🚀 Como Executar o Projeto

Para rodar o projeto localmente, siga os passos abaixo:

1. **Pré-requisitos**:
   - [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) instalado.

2. **Clonar o repositório**:
   ```bash
   git clone https://github.com/seu-usuario/LoginNexus.git
   cd LoginNexus
   ```

3. **Restaurar dependências**:
   ```bash
   dotnet restore
   ```

4. **Executar a aplicação**:
   ```bash
   dotnet watch run
   ```

5. **Acessar o portal**:
   Abra seu navegador em `https://localhost:5001` (ou a porta indicada no terminal).
